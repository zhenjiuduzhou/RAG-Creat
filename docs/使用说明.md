# RAG Studio 使用说明

1. 解压整个 `RAGStudio` 文件夹，双击 `RAGStudio.exe`。请勿单独移动 EXE；它需要同目录中的运行文件。
2. 点击“新建项目”，为客户或业务建立独立知识库。导入资料后，可点“预览”核对提取的文字和出处。
3. 点击“构建知识库”。默认模型首次使用会下载多语言向量模型；其后模型保存在本机，离线也可构建与检索。右上方“模型设置”可改用其他本地模型或 Embedding API，详见同目录《模型接入.md》。API 模式需要可访问模型服务，会发送资料片段和问题。扫描 PDF 和图片使用随程序打包的本地中英文 OCR。
4. 在“检索测试”中输入实际业务问题，检查相关片段和来源。增删资料后须重新构建，才可以检索或导出新版本。
5. 选择“Windows 完整版”并导出。本地模型模式的 ZIP 包包含检索服务、模型和索引；API 模式包含检索服务和索引，客户需另行配置模型 API 密钥。客户解压后运行 `start_windows.cmd`，无需安装 Python。
6. 每个知识库 ZIP 中的 `README.md` 提供通用 HTTP 工作流与 Dify 外部知识库的具体配置、知识库 ID 和提示词模板。

默认服务地址为 `http://127.0.0.1:8765`。云端工作流无法直接连接这台电脑的 `127.0.0.1`；需要将知识库包部署到它能访问的服务器，并按包内说明设置访问令牌、HTTPS 与网络访问控制。

原始资料默认不随知识库包导出，但导出包中的文本块仍含有资料内容，请按客户的数据要求保管。

构建产物保存在 `%LOCALAPPDATA%\RAGStudio`：模型由本机项目共享，项目目录保存导入资料的副本、提取缓存和当前索引。导出不重新向量化，而是复制当前索引，并加入模型、检索运行程序和接入说明生成新的 ZIP，因此本地项目与 ZIP 会同时占用空间；每个本地模型完整 ZIP 都带一份模型；API 模式不复制模型权重。导出期间还会使用临时目录，结束后自动清理。只需本机检索时可以不导出。

删除最后一份资料后，再点击“构建知识库”可生成空库并清理该项目的旧索引和缓存。已交付的旧 ZIP 需单独回收。图文混排 PDF 按页面文字长度判断是否 OCR；如果长电子页眉掩盖了扫描正文，请先对原文件进行 OCR 后导入。Dify 的非空元数据过滤条件目前会返回 422；需要按部门或密级隔离资料时，请为每个授权范围建立独立项目。
